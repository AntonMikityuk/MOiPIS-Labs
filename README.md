# Задание 3-1-1. Приемы моделирования бизнес-логики

**Вариант 4 — Жизненный цикл задачи в системе управления проектами**

## Архитектура

Решение реализовано как модуль `TaskTracker.ProcessEngine` в проекте TaskTrackerApp (`C:/TaskTrackerApp/src/TaskTracker.ProcessEngine`). Это управляемый данными движок процессов: классы объектов, пользователи/роли и шаблоны процессов описываются в YAML-файлах (YamlDotNet), а движок исполняет жизненный цикл объектов с проверкой ролей, условий в ДНФ и журналом истории.

- `Models/` — модели YAML-определений (классы, параметры, роли, пользователи, предикаты, состояния, переходы, шаблон процесса).
- `Runtime/` — `ProcessObject`, `HistoryEntry`, `OperationType`, `OperationResult`.
- `Engine/` — `ClassRegistry` (наследование, эффективные параметры), `UserRegistry`, `TemplateRegistry` (поиск действующего шаблона вверх по иерархии классов), `ConditionEvaluator` (предикаты и ДНФ), `ProcessEngine` (создание объекта, выполнение действия, изменение параметра, доступные действия, история).
- `YamlLoader` — загрузка YAML.

Тесты — `src/TaskTracker.ProcessEngine.Tests` (xUnit, 20 сценариев, YAML-данные в `TestData/`).

## Предметная область

- 3 класса: Задача -> Баг, Фича (наследование параметров; Баг переопределяет диапазон приоритета 1–3).
- 4 роли: аналитик, разработчик, тестировщик, менеджер проекта.
- 7 состояний: бэклог (начальное), анализ, разработка, ревью, тестирование, выполнено и отменено (конечные) — см. `task_lifecycle.yaml`.
- 11 переходов, условия записаны в ДНФ (например, быстрый путь бага: `[is_bug, high_priority]`, иначе `[not is_bug]` ИЛИ `[not high_priority]`).

## Запуск


## Использованная теория

- Задание 3-1-1 (МОиПИС/tasks/zadanie_3-1-1.pdf).
- Type Object — классы и параметры как данные, а не код.
- Flyweight — общие определения классов/шаблонов разделяются между объектами.
- Specification — предикаты и условия переходов (ДНФ).
- Command — операции создания, действия и изменения параметра с журналом.
- State — состояния и переходы жизненного цикла, заданные шаблоном.
